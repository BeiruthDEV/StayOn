Primeira versão pública do StayOn.

Durante uma sessão de foco, o app fecha os aplicativos que você escolher: abrir
o Instagram devolve você para a tela inicial até o tempo acabar. Funciona
offline, é gratuito, não pede cadastro e guarda tudo no próprio celular.

## Instalação

1. Baixe o `StayOn.apk` abaixo e abra o arquivo no celular. O Android vai pedir
   para permitir a instalação de uma fonte desconhecida.
2. No app, escolha o que barrar em **Foco → Apps bloqueados**.
3. Ative a permissão uma única vez em **Configurações → Acessibilidade →
   StayOn**. Sem ela o app funciona, mas não bloqueia nada.

Requer Android 7 ou mais novo.

## Limitação conhecida

Configurações → Aplicativos → StayOn → Forçar parada desliga o serviço de
acessibilidade e encerra o bloqueio até você reativá-lo na mão. Isso vale para
qualquer app de bloqueio e não é contornável: quem desliga é o Android. Fechar
pelo gerenciador de tarefas não muda nada — o bloqueio continua e a sessão volta
no mesmo ponto.
